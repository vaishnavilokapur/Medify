# Medify – Online Pharmacy Web Application

Medify is an online pharmacy web application developed using Python and Django.

## Features
- User registration and login
- Search and browse medicines
- Medicine details
- Order management
- AI-powered medicine assistant
- Admin management

## Technologies
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini API

## How to Run

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
